# Investment-Behavior-and-Insights-Using-Power-Bi

A Power BI dashboard project focused on analyzing investor behavior, investment preferences, savings objectives, and demographic-based investment patterns.

This project transforms raw investment data into meaningful business insights through interactive visualizations and analytics.

# Dashboard Preview


# Project Overview

The dashboard helps understand:

- Investor demographics
- Investment duration trends
- Gender-based investment behavior
- Preferred investment avenues
- Investment monitoring frequency
- Savings objectives
- Source of investment awareness

The analysis can help financial institutions, analysts, and investment firms better understand customer investment habits and decision-making patterns.

# Key Insights

***Investor Demographics***
- Total Investors: 40
- Average Age: 28
***Investment Frequency***

Most investors prefer:

- Monthly investments over weekly or daily investments.

***Gender-Based Analysis***
- Male investors make up a larger percentage of total investors.
- Investment preferences vary significantly between male and female investors.

***Investment Duration***

Most participants prefer investments between:
- 1–5 years
- 3–5 years


***Popular Investment Sources***

Top investment awareness sources:

- Financial Consultants
- Newspapers & Magazines

***Investment Objectives***

Common investor goals include:

- Better Returns
- Retirement Planning
- Fund Diversification
